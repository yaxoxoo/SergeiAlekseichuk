# Sergei Alekseichuk — SMM Barcelona

Лендинг SMM-специалиста из Барселоны. Статический сайт: editorial serif-типографика, плавный скролл (Lenis), переключение языков ES/EN, scroll-spy в меню.

## Структура
- `index.html` — разметка
- `style.css` — стили (всё в rem, BEM, брейкпоинты в em)
- `script.js` — Lenis, scroll-spy, reveal, переключатель языка
- `assets/` — портрет и фото проектов

## Локальный запуск
```bash
python3 -m http.server 4321
# открыть http://localhost:4321
```
